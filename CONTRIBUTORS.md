### How to add yourself

If you contribute to this project, please add your name to the **Community Contributors** section above as part of your pull request.

Add your name with a brief role description — what you own or contribute to in the project (e.g., "Python SOP Templates," "Documentation," "Cursor Integration").

Example:

```markdown
| [Your Name] | [Your Role] | [@username](https://github.com/username) |
```
